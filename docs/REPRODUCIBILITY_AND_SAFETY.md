# Reproducibility and Safety

Use Python 3.10, 3.11, or 3.12. From a clean checkout install with `python -m pip install -e '.[dev]'`, then run `ruff check .`, `pytest -q`, `python benchmarks/heldout_suite.py`, `python examples/minimal.py`, `python examples/complete.py`, and `python run.py`.

F51 is advisory only. It must not be used to diagnose, prescribe, autonomously modify medication or treatment, or replace emergency services or qualified clinicians. Emergency red flags trigger escalation. High uncertainty, missing evidence, incomplete consent/privacy/identity checks, unresolved conflicts/questions, and required-but-incomplete clinician review all prevent routine approval. Consequential healthcare decisions remain under qualified human authority.
